# Documentation images

`menu.png` is a clearly labelled menu-content preview generated by the app's
`--screenshot-fixture` mode. The preview renders the same attributed
`NSMenuItem` content factory the production menu uses, using fixed sample
values. It is not a capture of a desktop, menu bar, account, power state, or
native menu window.

The executable exits from that mode before it creates `NSApplication`, reads
or changes `pmset`, starts `caffeinate`, creates timers, or interacts with a
LaunchAgent.
